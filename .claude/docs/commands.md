# 슬래시 커맨드 11개

`.claude/commands/{name}.md`. 전부 **얇은 진입점**이고 실제 절차는 같은 이름의 스킬에 있다 — [`skills.md`](skills.md).

## 자주 쓰는 형태

```bash
/work #12 feature        # 새 기능
/work #34 fix            # 버그 수정
/work #56 quick          # 계획 생략, 바로 구현
/work #12                # 타입 미지정 → 추정 후 확인 질문

/pr-review 7             # PR #7 코드 리뷰
/pr-review 7 --comments  # PR #7 에 달린 코멘트 대응
```

`/work` 는 **타입을 추정만으로 진행하지 않는다.** 타입이 브랜치·리뷰 깊이·PR 방식을 전부 좌우하므로
미지정이면 반드시 확인 질문을 띄운다.

## 왜 커맨드와 스킬이 따로 있나

- **커맨드** — 사용자가 치는 이름. 인자 힌트를 제공한다
- **스킬** — 실제 절차. 키워드로도 발동하고, 다른 스킬이 호출하기도 한다

커맨드에 절차를 복제하면 둘이 어긋난다. 커맨드는 **항상 포인터로만** 둔다.
