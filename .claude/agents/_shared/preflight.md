# 사전 점검 프로토콜 (Charter Preflight)

모든 에이전트는 작업 시작 전 아래 5줄을 출력하여 올바른 문제를 풀고 있는지 확인한다.

```
CHARTER_CHECK:
1. 목표: {한 줄로 요약}
2. 스코프: {수정 대상 파일/영역}
3. 제약: {하지 말아야 할 것}
4. 완료 조건: {무엇이 되면 끝인가}
5. 위험: {잘못될 수 있는 것}
```

## 규칙

- 작업 시작 전 **반드시** 출력한다
- 5번 항목(위험)이 비어있으면 "없음"이 아니라 한 번 더 생각한다
- Charter와 실제 작업이 다르면 즉시 중단하고 보고한다
