## 1. 원인

`.claude/scripts/secret-scan.sh:120` 의 개인키 검사가 **줄 앵커**다.

```bash
grep -nE '^-+ ?BEGIN [A-Z0-9 ]*PRIVATE KEY( BLOCK)?'
```

`^` 바로 뒤에 대시를 요구하므로 **선행 공백이 한 칸이라도 있으면 빠져나간다.**

**재현했다.** 두 파일을 만들어 현재 패턴에 걸어 봤다.

| 파일 | 현재 패턴 |
|---|---|
| `flush.txt` — 헤더가 col 0 | 🚫 차단 |
| `indented.yaml` — k8s Secret 모양(4칸) | 🔴 **통과 — 커밋된다** |

```yaml
stringData:
  tls.key: |
    -----BEGIN RSA PRIVATE KEY-----      ← ^ 에 걸리지 않는다
```

k8s Secret · Helm values · GitHub Actions 가 전부 이 모양이고, **키가 저장소에 실제로
나타나는 1순위 형태**다. #28 의 런타임 스크럽(`TokenRedactor`)은 이 형태를 이미 막지만,
**커밋 차단은 못 막는다** — 방어 두 겹 중 앞쪽이 뚫려 있다.

### 🔴 이슈에 적은 완료 조건이 틀렸다

이슈 본문에 이렇게 적어 뒀다.

> 고치는 법: `^` 하나를 지우면 된다.
> - [ ] `SCAN_MODE=tree` 로 **히트 0건 확인**

**둘 다 측정하지 않고 쓴 말이다.** 앵커를 빼고 추적 파일 333개를 돌리면 **25건**이 나온다 —
전부 #28 이 남긴 것들이다.

| 히트 | 예 |
|---|---|
| javadoc 설명 | `* {@code -----BEGIN PGP PRIVATE KEY BLOCK-----} 는 사이에…` |
| 테스트 픽스처 | `String pem = "-----BEGIN RSA PRIVATE KEY-----";` |

그대로 머지하면 **`main` 이 적색**이 되고, 그 파일들을 건드리는 모든 커밋이 막힌다.

⚠️ `testing-philosophy.md` 에 「성능 주장은 측정하지 않으면 적지 않는다」를 넣은 직후에
**완료 조건을 측정 없이 적었다.** 같은 실패가 축만 바꿔 나타났다 — 성능이 아니라 범위였다.

## 2. 수정

**선행 공백만 허용한다.** 앵커를 없애는 것이 아니라 **한 칸 옮긴다.**

```diff
- grep -nE '^-+ ?BEGIN [A-Z0-9 ]*PRIVATE KEY( BLOCK)?'
+ grep -nE '^[[:space:]]*-+ ?BEGIN [A-Z0-9 ]*PRIVATE KEY( BLOCK)?'
```

**왜 이것이 옳은 선을 긋는가** — 실제 키 파일에서는 헤더가 **줄의 처음**(들여쓰기 제외)에
온다. 소스 코드에서 헤더가 등장할 때는 앞에 `"` · `*` · `String x = ` 같은 것이 붙는다.
구분하려는 것이 정확히 그 차이다.

| 실측 | 안 A (앵커 제거) | **안 B (선행 공백 허용)** |
|---|---|---|
| `indented.yaml` (구멍) | 🚫 차단 | 🚫 **차단** |
| `flush.txt` | 🚫 차단 | 🚫 차단 |
| **추적 파일 333개** | 🔴 **25건** | ✅ **0건** |

⚠️ **안 A 를 택하면 `main` 이 적색이 된다.** 이슈가 제안한 것이 안 A 였다.

### 남는 구멍 — 숨기지 않는다

이 수정이 막지 **못하는** 것:

- `key = "-----BEGIN RSA PRIVATE KEY-----"` 처럼 **소스 리터럴 안에** 통째로 박은 키.
  허용이 의도다 — 그 형태를 막으면 `TokenRedactorTest` 자신이 커밋되지 않는다
- 한 줄로 이어붙인 JSON 임베드 (`{"key":"-----BEGIN…\n…"}`)

둘 다 **런타임 쪽(`TokenRedactor`)은 막는다.** 여기서 닫는 것은
「키 **파일**을 커밋하지 마라」이지 「키 문자열이 소스에 없게 하라」가 아니다.
그 구분을 스크립트 주석에 적는다.

| 2 | col 0 개인키는 계속 차단된다 (회귀) | `flush.txt` |

| 4 | **드리프트 테스트가 이 형태에 양성 대조를 갖는다** | `SecretPatternDriftTest` 의 PEM 샘플을 **들여쓴 형태**로 바꾼다 |
| 5 | 그 샘플이 스크립트 정규식에 **실제로 물린다** | 그 테스트에 이미 있는 검사 |
| 6 | 물림 | 앵커를 되돌리면 4가 빨개진다 |

### 4번이 이 PR 의 핵심이다

#28 은 커밋 차단과 런타임 스크럽의 어긋남을 검출하는 `SecretPatternDriftTest` 를 만들었지만,
**이 구멍에 대해서는 양성 대조를 갖지 못했다** — 대응표의 PEM 샘플이 **줄 시작**이라
현재 패턴에도 물려서 초록이었다.

> 위반이 0건인 상태에서 초록은 「막혔다」의 증거가 아니라 「지금 위반이 없다」의 증거다
> — `testing-philosophy.md`

샘플을 들여쓴 형태로 바꾸면 **패턴이 좁아지는 순간 빨개진다.** 그게 「샘플이 먼저
대표여야 한다」의 실제 적용이다.
