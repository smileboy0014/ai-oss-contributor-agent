# PLAN 템플릿

`docs/plans/PLAN-{issue}.md` 로 저장한다. 해당 없는 절은 **삭제하지 말고 「해당 없음 — 근거」로 남긴다.**
빈칸이 아니라 판단이 기록되어야 다음 세션이 다시 묻지 않는다.

### 데이터 모델 (해당 시)

| 테이블 | 컬럼 | 타입 | 제약 |
|---|---|---|---|

⚠️ 스키마 정본은 **Flyway 마이그레이션**(`db/migration`)이고 `ddl-auto` 는 `validate` 다.
엔티티를 추가·변경하면 **같은 커밋에 마이그레이션 파일**을 넣는다. 적용된 파일은 고치지 않고 새 버전을 쌓는다.
SQL 은 **H2·PostgreSQL 공통 문법**만 쓴다(벤더 고유 문법 금지) — Q-2.
